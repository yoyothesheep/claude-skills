# AI-tells checklist (Deliver stage)

None of these are wrong in isolation — they become tells once a user has seen them in every
third generated design. Don't ban outright (that just pushes the model into stranger
substitutes) — try the alternative, show both, keep whichever's better.

| Overused pattern | Looks like | Try instead |
|---|---|---|
| Eyebrow text | Small all-caps label restating the headline ("EXPENSE MANAGEMENT" above "Control company spending") | Delete it — nine times out of ten, nothing is lost |
| Generic gradient backgrounds | Purple/blue gradient behind hero copy, no other texture | A real image, a pattern, or a flat color |
| Excessive cards/containers | Every section boxed, even simple 3-item lists | Flatter layouts — grids, tiles, no border |
| Too many fonts/text styles | 4+ type treatments on one screen | 1-2 fonts, 2-4 styles; accent sparingly |
| Same layout every time | Text-left/graphic-right hero, regardless of brief | Vary structure per direction — a Discover-stage fix, not Deliver |
| Decorative elements with no function | Glows/blobs/icons that carry no state or information | Cut it unless it does real work |
| AI-voiced copy | Long, hedge-y, overexplaining marketing copy | Human rewrite pass — shorter, plainer, in a real voice |
| Manila folder / oat-milk wash | Defaulting to `#F4EFE6` or `#F5EDD6` beige/cream background on everything | Crisp optical whites (`#FFFFFF`, `#F8F9FA`), warm stone, rich tint, or deliberate dark mode |
| Terminal / bracket UI in consumer apps | `[X]`, `[ + ADD ]`, `// INDEX`, `FIG. 01`, `FAMILY_ID: H-409` | Clean natural labels, authentic mobile segmented controls, and standard system icons |
| Hairline grid overdose | Black `1px solid #141412` wireframe boxes around every paragraph, label, and photo | Use whitespace, tonal surface fills, and typography hierarchy instead of black box cells |

Go pattern by pattern. For each one present, ask: information or filler? If filler, show both
the original and the "try instead" version — report the change, don't silently swap it.
